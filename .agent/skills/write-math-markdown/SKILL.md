# Писать Markdown с математикой

## Правила разметки

- Для короткой формулы внутри предложения используйте `$...$`; для отдельной формулы — `$$` на отдельных строках с пустой строкой до и после блока.
- Не помещайте `$$` в середину абзаца и не оборачивайте математическое выражение в обратные кавычки.
- В матрицах явно задавайте столбцы через `&`, строки разделяйте `\\`, используйте `\begin{pmatrix}...\end{pmatrix}` или `\begin{bmatrix}...\end{bmatrix}`. Не пишите обратный слеш перед числом или переменной вместо разделителя строк.
- Для систем и многострочных выкладок используйте поддерживаемые KaTeX окружения `aligned`, `cases` и матрицы; ставьте `&` у знаков равенства для выравнивания.
- Экранируйте символы Markdown в математике только при необходимости. Математические знаки `_`, `^`, `\`, `{}` должны находиться внутри математических разделителей.
- В научном тексте задавайте обозначения и нормировку до вывода формул; следите, чтобы подстрочные индексы, знаки сопряжения, скобки и множители были однозначны.

## Проверка перед завершением

1. Просмотрите исходный Markdown: каждый display-блок должен иметь отдельные строки `$$`, а матричные строки — корректные `&` и `\\`.
2. Откройте Preview GitHub или Jupyter и проверьте визуально начало, середину и конец документа. Исправьте формулы, показанные как сырой LaTeX или с потерянной строкой/столбцом.
3. Для формул физической модели сверьте соглашения с кодом проекта и независимой проверкой; корректный рендер сам по себе не подтверждает математику.

## Пример

```markdown
Локальная компонента в базисе $(|\downarrow\rangle,|\uparrow\rangle)$:

$$
S^z=\left(\begin{smallmatrix}-\frac12&0\\0&\frac12\end{smallmatrix}\right).
$$
```
